# 言語的境界screening seed 42暫定メモ

作成日: 2026-08-18

## 条件

- checkpoint: seed 42、step 55
- inference constraint: `utf8-hard`（学習条件と一致）
- 主比較: 共通境界予算 `central`（stage 0: 3.0 byte/chunk、stage 1: 3.0 unit/chunk）
- 主指標: stage 1の言語的説明可能性
- UTF-8途中境界率と速度は順位に使用しない

## 集約結果

| model | precision | coverage | pathological record rate |
| --- | ---: | ---: | ---: |
| K3G1 | 0.500 | 0.292 | 0.083 |
| K1G1 | 0.489 | 0.306 | 0.000 |
| K3T1 | 0.463 | 0.264 | 0.000 |
| T26 | 0.444 | 0.222 | 0.000 |
| K1T1 | 0.372 | 0.222 | 0.000 |
| M3T1 | 0.283 | 0.181 | 0.083 |

## 目視所見

- K1G1は活用語尾、助動詞、助詞、複合語で比較的広く説明可能な境界を形成した。
  `笑/っている`、`書/いている`、`変更/していない`に相当する分割が確認できた。
- K3T1も活用語尾、助動詞、複合語でK1G1に近い傾向を示し、病的断片化はなかった。
- T26は病的断片化がなく、比較baselineとして残す価値がある。一方、coverageは上位2候補より低い。
- K3G1はaggregate precisionが最大だったが、`[分][割][の]`、`[値][が][正]`のような
  連続短断片があり、活用・助動詞spanでは境界をほぼ形成しなかった。
- M3T1にも連続短断片があり、主要指標は最下位だった。
- 全候補で文脈依存pairの厳格なpass条件を満たさなかった。seed 42、step 55だけでは
  動的文脈適応を確認できず、中規模ではcheckpoint推移とseed再現性を調べる。

## 中規模候補

暫定的にK1G1、K3T1、T26をPhase Cへ進める。

K3T1は55-step calibrationでratio weight 0.08のとき、validation BPB 2.5005、
compression L2/L0 11.09だった。ratio weight 0.05の旧K3T1は圧縮率の乖離が大きかったため、
中規模学習では0.08を用いる。

この選抜は長期性能の証明ではなく、言語的に説明可能な分割を長期候補のproxyとする
計画上の暫定判断である。
